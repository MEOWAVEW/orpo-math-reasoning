重叠检查仅移除两种已知指令后缀、折叠空白并忽略大小写，不覆盖语义近重复或上游预训练污染。机器报告中的排除重叠后统计复用历史 `correct`，仅是诊断，不能替代重新训练和独立评分。

原始 D2 含两处 U+2028，位于题目字符串内，是合法 JSON；JSONL 必须以 LF 分隔，不能使用会额外拆开 Unicode 分隔符的 `str.splitlines()`。全部原始预测通过严格逐行 JSON 解析，本次没有修复或修改预测。
