# Historical notebooks

These notebooks are archived working material, not the primary reproduction entry point.

- `final-4.ipynb` retains an older 500-sample, 200-step run. It is not the recovered 250-step run documented in the main README.
- `aimoeval-math-accurac.ipynb` preserves a historical evaluation attempt and Kaggle paths. Its saved output is not a complete evaluation report.
- `kaggle_aimo_orpo_rewrite.ipynb` is a data-construction prototype.

Use `scripts/audit_evidence.py` for archived evidence, `scripts/prepare_clean_data.py` for new splits, and `scripts/evaluate.py` for new model comparisons. Historical scoring remains available in the immutable copies under `evidence/evaluation/`.
